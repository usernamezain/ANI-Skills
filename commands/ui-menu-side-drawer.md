# ui:menu-side-drawer

Build a navigation menu that slides in from the left or right edge of the screen as a fixed-width drawer/panel, with a dimmed backdrop and staggered link entrance. Use whenever the user wants a "side menu", "slide-in nav", "drawer menu", "side panel navigation", or "menu from the side" — distinct from a fullscreen overlay in that it stays a partial-width panel rather than covering the whole viewport.

**Skill folder:** `skills/side-drawer-nav-menu/`
**Namespace:** `ui`
