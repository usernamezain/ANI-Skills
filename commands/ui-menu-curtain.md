# ui:menu-curtain

Build a navigation menu that drops down from the top of the screen like a curtain or roller blind, covering the page as it descends, with links revealing as the panel unrolls. Use whenever the user wants a "menu that comes from the top", "dropdown curtain menu", "menu that slides down", or "top-down reveal navigation" — distinct from a fullscreen overlay in that the panel itself visibly grows downward rather than instantly covering the viewport.

**Skill folder:** `skills/top-down-curtain-menu/`
**Namespace:** `ui`
