# ui:portfolio-hover-grid

Build a portfolio/work grid where thumbnails reveal a preview image, project title, or video on hover, with a staggered scroll-triggered entrance for the grid items. Use whenever the user wants a "portfolio section", "project grid", "work showcase", "case study grid", or "hover to preview" gallery. Combines gsap-scrolltrigger-effects (entrance) with custom-cursor-effects (hover preview follow-cursor pattern).

**Skill folder:** `skills/portfolio-hover-reveal-grid-section/`
**Namespace:** `ui`
