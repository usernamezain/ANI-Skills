# ui:menu-split-panel

Build a navigation menu where two panels split open from the center (or one panel wipes across) to reveal fullscreen navigation underneath, like theater curtains parting. Use whenever the user wants a "split menu", "panels that open", "curtain-style menu split down the middle", or a more dramatic/cinematic alternative to a simple fade-in fullscreen overlay.

**Skill folder:** `skills/split-panel-menu-reveal/`
**Namespace:** `ui`
