# ui:hamburger-morph

Build an animated hamburger-to-X menu trigger icon with smooth line morphing, plus a text-label variant ("Menu" to "Close") and a circular progress/hover ring around the button. Use whenever the user wants a "hamburger menu icon", "animated menu button", "hamburger to X animation", or "menu open/close icon transition" — this is the trigger-button skill, pair it with any of the menu-container skills (fullscreen-menu-overlay, side-drawer-nav-menu, top-down-curtain-menu, split-panel-menu-reveal).

**Skill folder:** `skills/morphing-hamburger-icon/`
**Namespace:** `ui`
