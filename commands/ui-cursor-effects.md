# ui:cursor-effects

Build custom mouse-cursor effects and cool hover interactions — magnetic buttons, cursor-follow blobs, mix-blend-mode cursors, cursor trails, image/text hover distortion, and 3D tilt-on-hover cards. Use whenever the user mentions "custom cursor", "magnetic button", "hover effect", "cursor trail", "mouse follow", "tilt card", "3D hover", or "cool hover animation". Always disable/adjust these on touch devices since there is no cursor.

**Skill folder:** `skills/custom-cursor-effects/`
**Namespace:** `ui`
