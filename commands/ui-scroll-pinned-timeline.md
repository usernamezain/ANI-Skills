# ui:scroll-pinned-timeline

Build a vertical timeline/roadmap/milestones section where a progress line draws itself and milestone cards light up as the user scrolls past them, with an optional pinned variant where the timeline stays centered while entries scroll past. Use whenever the user wants a "timeline section", "roadmap", "milestones", "our history", or "process steps section".

**Skill folder:** `skills/scroll-pinned-timeline-section/`
**Namespace:** `ui`
