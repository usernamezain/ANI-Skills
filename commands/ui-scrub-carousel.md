# ui:scrub-carousel

Build a testimonials section where quote cards scroll horizontally, driven either by a scroll-scrubbed timeline or by draggable/auto-playing carousel controls. Use whenever the user wants a "testimonials section", "reviews carousel", "quote slider", or "customer feedback section". Two variants included — scroll-scrubbed (tied to page scroll) and self-contained carousel (autoplay/drag, independent of page scroll).

**Skill folder:** `skills/scrub-carousel-testimonials-section/`
**Namespace:** `ui`
