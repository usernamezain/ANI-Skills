# ui:responsive-qa

Systematically verify a site actually works across real devices, viewports, pointer types, and browsers — not just "looks fine in one browser window." Use after building any responsive or animated section, whenever the user asks to "test", "make sure it works everywhere", "check responsiveness", or reports something "breaks/looks wrong" on a specific device. This is a verification checklist skill, not a code-pattern skill.

**Skill folder:** `skills/cross-device-responsive-qa/`
**Namespace:** `ui`
