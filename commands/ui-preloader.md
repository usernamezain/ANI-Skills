# ui:preloader

Build page preloaders and loading-state animations — percentage counter preloaders, progress bars, skeleton screens, spinner/morph loaders, and staged reveal-after-load sequences. Use whenever the user asks for "preloader", "loading screen", "loading animation", "progress bar", "skeleton loading", "spinner", or "splash screen". Distinct from scroll-triggered reveals — these run once on initial page load, gated by real asset-load events, not scroll position.

**Skill folder:** `skills/preloader-visual-loading/`
**Namespace:** `ui`
