# ui:hero-parallax

Build a cinematic full-viewport hero section with layered parallax depth, a staggered GSAP intro timeline, and scroll-fade-out on exit. Use whenever the user wants a "hero section", "landing page header", "cinematic intro", or "parallax hero" — especially for agency, film, product-launch, or portfolio landing pages. Pairs with gsap-scrolltrigger-effects and text-motion-typography skills for the entrance/scroll motion.
