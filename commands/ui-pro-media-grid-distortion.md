# ui:pro-media-grid-distortion

Generate an interactive WebGL-based grid displacement distortion canvas using Three.js DataTexture and custom shaders. Features chromatic aberration (RGB channels split) responsive to mouse gesture speeds, relaxation friction physics, and automatic container aspect ratio cover fitting. Use this skill when the user requests grid distortion, mouse ripples on images, interactive liquid picture distortion, or chromatic WebGL image hover warp effects.

**Skill folder:** `skills/pro/media/grid-distortion/`
**Namespace:** `ui`
