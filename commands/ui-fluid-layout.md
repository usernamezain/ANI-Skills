# ui:fluid-layout

Build truly fluid, precise responsive layouts using clamp()-based typography and spacing, container queries, and an intentional breakpoint strategy — instead of the common shortcut of just scaling a desktop design down at 2-3 fixed breakpoints. Use whenever the user wants a site to be "responsive", "look good on every screen", "fluid", or asks to fix layout breaking/overflow at certain widths. Foundational for any portfolio or section skill — apply this before layering animation on top.

**Skill folder:** `skills/fluid-responsive-layout-system/`
**Namespace:** `ui`
