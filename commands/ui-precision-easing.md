# ui:precision-easing

Choose and tune animation easing curves with actual motion-design intent — custom cubic-bezier curves, GSAP's expanded ease library, and the physical-motion principles (anticipation, overshoot, follow-through) that separate "buttery" animation from generic linear/ease-in-out defaults. Use whenever the user says "make it feel smoother", "buttery", "more premium/polished motion", "the animation feels stiff/robotic", or asks about timing/easing specifically.
