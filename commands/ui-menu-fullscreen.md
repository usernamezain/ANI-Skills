# ui:menu-fullscreen

Build a fullscreen navigation overlay with huge staggered text links that covers the entire viewport when opened — the classic agency-site menu pattern. Use whenever the user wants a "fullscreen menu", "huge text nav", "menu that takes over the screen", "big link list menu", or an alternative to a small dropdown/hamburger panel. Pairs with morphing-hamburger-icon for the trigger button and precision-easing-motion-design for the reveal timing.
