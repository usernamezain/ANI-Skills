# ui:horizontal-scroll-gallery

Build an image/project gallery section where vertical page scroll drives horizontal panel movement, with each panel slightly scaling/parallaxing as it passes center. Use whenever the user wants a "horizontal scroll gallery", "horizontal scrolling section", "sideways scroll", or "image showcase that scrolls sideways". Extends the horizontal-scroll pattern from gsap-scrolltrigger-effects with per-panel scale/parallax detail.

**Skill folder:** `skills/horizontal-scroll-gallery-section/`
**Namespace:** `ui`
