# ui:stagger-blog-cards

Build a blog/article listing section with staggered scroll-triggered card entrances, image zoom-on-hover, animated read-time/category tags, and optional filterable category tabs with a GSAP FLIP-style layout transition. Use whenever the user wants a "blog section", "articles grid", "news section", or "insights listing".

**Skill folder:** `skills/stagger-reveal-blog-cards-section/`
**Namespace:** `ui`
