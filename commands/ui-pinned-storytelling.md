# ui:pinned-storytelling

Build a pinned "about" or brand-story section where the section sticks in place while a sequence of copy/images crossfades or slides as the user keeps scrolling — the classic scrollytelling technique. Use whenever the user wants an "about section", "our story", "scrollytelling", "pinned narrative section", or a section where "text changes as I scroll but stays in place". Built directly on the gsap-scrolltrigger-effects skill's pin+scrub pattern.

**Skill folder:** `skills/pinned-storytelling-about-section/`
**Namespace:** `ui`
