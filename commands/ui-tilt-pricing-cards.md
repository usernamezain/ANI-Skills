# ui:tilt-pricing-cards

Build a pricing section with 3D tilt-on-hover cards, a highlighted/featured plan that scales up, and a monthly/yearly toggle animated with GSAP. Use whenever the user wants a "pricing section", "pricing cards", "plans comparison", or "subscription tiers" with polish beyond static cards. Builds on custom-cursor-effects' tilt-card pattern.
