# ui:morph-mask-reveal

Build morph and mask reveal animations — shape morphing between SVG paths, clip-path mask wipes/reveals for images and sections, page/section transition overlays, and blob morph loaders. Use whenever the user asks for "morph animation", "mask reveal", "clip path reveal", "shape morph", "page transition", "wipe transition", or "blob animation". These are distinct from simple opacity fades — the defining trait is a moving edge/boundary that reveals or reshapes content.

**Skill folder:** `skills/morph-mask-reveal-transitions/`
**Namespace:** `ui`
