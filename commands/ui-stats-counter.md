# ui:stats-counter

Build a stats/metrics section where numbers count up as they scroll into view, with staggered timing, animated separators, and an optional circular progress ring per stat. Use whenever the user wants a "stats section", "numbers section", "metrics counter", "by the numbers", or "achievements section". Uses the counter pattern from text-motion-typography, extended with layout and ring variants.

**Skill folder:** `skills/animated-stats-counter-section/`
**Namespace:** `ui`
