# ui:mask-reveal-footer

Build a footer section that reveals itself with a rising mask/curtain as the user scrolls to the bottom of the page, plus a large animated logo/wordmark and staggered link columns. Use whenever the user wants a "footer section", "site footer", "curtain reveal footer", or "footer that slides up from the bottom". Builds on morph-mask-reveal-transitions for the curtain effect.

**Skill folder:** `skills/mask-reveal-footer-section/`
**Namespace:** `ui`
