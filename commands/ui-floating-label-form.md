# ui:floating-label-form

Build a contact form section with animated floating labels, focus-state underline draw-in, inline validation micro-shakes, and a success-state morph on submit. Use whenever the user wants a "contact form", "contact section", "get in touch form", or a form with more polish than default browser styling. Pairs with morph-mask-reveal-transitions for the submit success state.

**Skill folder:** `skills/floating-label-contact-form-section/`
**Namespace:** `ui`
