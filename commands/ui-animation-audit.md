# ui:animation-audit

Audit and fix an animated site's accessibility (prefers-reduced-motion, keyboard/focus, screen-reader compatibility with split text and hover-only reveals) and performance budget (Lighthouse/CLS/long-tasks) before calling it finished. Use as a final pass after building any animated portfolio or section, or whenever the user asks to "make it accessible", "check performance", "improve Lighthouse score", or "fix accessibility issues".

**Skill folder:** `skills/animation-accessibility-performance-audit/`
**Namespace:** `ui`
