# ui:text-motion

Animate text and typography — interactive/variable fonts that react to hover or mouse position, character/word/line stagger reveals, animated counters, typewriter effects, and text loading animations. Use whenever the user asks for "text animation", "interactive font", "animated headline", "text reveal", "typewriter", "split text", "counter animation", or "text loading". Covers both GSAP SplitText-style and dependency-free approaches.
