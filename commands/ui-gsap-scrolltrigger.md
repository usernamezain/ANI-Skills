# ui:gsap-scrolltrigger

Build scroll-driven animations with GSAP + ScrollTrigger — scroll scrubbing, pinned sections, parallax layers, horizontal scroll sections, and animated scroll progress bars. Use this skill whenever the user asks for "scroll animation", "pin a section", "scroll scrub", "parallax", "sticky scroll", "scroll progress bar", "reveal on scroll", or any component whose motion should be tied to scroll position rather than time. Always use this skill before hand-writing scroll listeners — GSAP ScrollTrigger is more accurate and performant than manual IntersectionObserver/scroll-event code.

**Skill folder:** `skills/gsap-scrolltrigger-effects/`
**Namespace:** `ui`
