# ai:eval-auditor

Retroactive audit of an implemented AI phase's evaluation coverage. Checks implementation against the AI-SPEC.md evaluation plan. Scores each eval dimension as COVERED/PARTIAL/MISSING. Produces a scored EVAL-REVIEW.md with findings, gaps, and remediation guidance. Spawned by /antigravity:eval-review orchestrator.

**Skill folder:** `skills/eval-auditor/`
**Namespace:** `ai`
