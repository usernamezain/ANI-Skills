# marketing:data-import

Import CSV, JSON, or Google Sheets data into a connected CRM, email platform, or audience store — auto-suggested field mapping, validation, dedup against existing records, consent verification, and batched writes behind a mandatory approval gate, with rollback guidance. Produces a per-record import results report. Triggers on \"/digital-marketing-pro:data-import\", \"import this CSV of leads into HubSpot\", \"load subscribers into Mailchimp\", \"half these rows have bad emails\", \"dry-run this import first\". Reads brand compliance rules (GDPR, CAN-SPAM, CCPA) for contact data and executes through the destination platform's connected MCP.
