# ui:hero-split-text

Build a minimal, typography-first hero section where the headline reveals character-by-character or line-by-line through masked slits, followed by a subtle scroll-scrub zoom. Use for editorial, SaaS, or design-studio landing pages where the user asks for a "text-focused hero", "big typography hero", "line reveal headline", or a cleaner alternative to an image-heavy hero. Pairs with text-motion-typography for the split logic.

**Skill folder:** `skills/hero-split-text-reveal-section/`
**Namespace:** `ui`
