# ui:menu-mega-dropdown

Build a multi-column mega-menu dropdown that expands beneath a nav item on hover/click, with grouped link columns and an optional live image preview panel that swaps based on which link is hovered. Use whenever the user wants a "mega menu", "dropdown with columns", "nav menu with preview images", or a menu structure for a site with many sections/categories that a simple link list can't organize well.

**Skill folder:** `skills/mega-menu-dropdown/`
**Namespace:** `ui`
