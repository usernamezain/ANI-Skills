# ui:threejs-backgrounds

Build WebGL 3D effects with three.js — particle field backgrounds, mouse-reactive 3D objects, scroll-linked 3D scenes, and interactive shader gradients. Use whenever the user asks for "3D background", "particle effect", "webgl", "three.js scene", "3D hover object", or wants a hero section with depth/motion beyond flat CSS/SVG. Always include cleanup/dispose logic and a resize handler — these are the most commonly missed pieces in three.js code.
