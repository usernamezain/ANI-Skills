# mobile:nixie-fx-runtime

Integrate compiled NixieFX particle effects into PixiJS or Three.js applications using the public nixie-fx package. Use when an agent needs to install the runtime, load an out/vfx export bundle, implement texture or material providers, mount a renderer, drive effects from a game loop, inspect runtime diagnostics, or clean up NixieFX resources.

**Namespace:** `mobile`
