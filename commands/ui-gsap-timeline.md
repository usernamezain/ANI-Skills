# ui:gsap-timeline

Sequence complex multi-element animations precisely using GSAP timelines — labels, relative position parameters, nested timelines, and function-based stagger — instead of chaining many separate tweens with guessed delay values. Use whenever an animation involves more than 2-3 elements that need to move in relation to each other (hero entrances, multi-step reveals, coordinated section transitions), or when the user says animations feel "out of sync" or "the timing is off.

**Skill folder:** `skills/gsap-timeline-choreography/`
**Namespace:** `ui`
