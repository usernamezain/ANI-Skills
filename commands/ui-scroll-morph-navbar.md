# ui:scroll-morph-navbar

Build a navbar that morphs on scroll — shrinks in height, adds a background/blur, and can hide-on-scroll-down/show-on-scroll-up. Use whenever the user wants a "sticky navbar", "shrinking header", "navbar that changes on scroll", or "hide navbar on scroll down". Pairs with buttery-smooth-120fps-performance for the rAF-throttled scroll listener.

**Skill folder:** `skills/scroll-morph-navbar-section/`
**Namespace:** `ui`
