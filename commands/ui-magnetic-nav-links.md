# ui:magnetic-nav-links

Style huge oversized navigation link text with per-letter magnetic cursor attraction, outline-to-fill hover fill effects, and an animated active-page indicator — the link-styling layer to drop into any fullscreen/drawer/curtain menu skill. Use whenever the user wants nav links that feel "alive" or "magnetic", huge display-sized menu type, or a fill/outline hover effect on menu items. This is a styling layer, not a full menu container — pair it with fullscreen-menu-overlay, side-drawer-nav-menu, top-down-curtain-menu, or split-panel-menu-reveal for the container/open-close mechanics.

**Skill folder:** `skills/magnetic-huge-text-nav-links/`
**Namespace:** `ui`
