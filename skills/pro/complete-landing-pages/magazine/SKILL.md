# Magazine Complete Landing Page

A top-tier luxury editorial layout blending high-fashion magazine grids (such as Vogue) with smooth spring-physics based image dragging, bold typography, and modular catalog directory structures.

## Features

- **Fluid Floating Image Cursor**: Highly optimized mouse-tracking modal that swaps article preview panels, utilizing Framer Motion `useSpring` and `useMotionValue` to drag the overlay smoothly behind the cursor.
- **Asymmetrical Visual Index**: Off-center grid galleries staggering images vertically in dynamic alignments (`md:mt-24` vs `md:mb-24`).
- **Premium Subscription Banners**: Simple parallax subscription covers leveraging full viewport grids.
- **Typographic Category Directory**: Giant bold category lists featuring custom horizontal layout animations.
- **Editorial Spotlight**: Clean product highlights accompanied by monospaced specs.

## Technical Details

- **Animation Engine**: `framer-motion`
- **Cursor Mechanics**: `useSpring`, `useMotionValue`
- **Icons**: `lucide-react`
- **Styling**: Tailwind CSS
