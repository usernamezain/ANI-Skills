# Dimensions Complete Landing Page

A premier, award-winning-style creative landing page focusing on geometric depth, axis-shifting interactions, and professional scroll pacing.

## Features

- **Split Text Reveals**: Character-by-character GSAP 3D rotations on viewport entry.
- **Axis Shifting (Horizon X)**: Scroll-jacked vertical-to-horizontal pinning using GSAP `ScrollTrigger` and viewport container tween mappings.
- **Vertical Parallax Masonry**: Multi-column grids moving at different scroll ratios (`yPercent` offsets).
- **Exploding Bento Grid**: Aggressive 3D bento items performing custom entry rotation (`rotationX: 45`, `scale: 0.8`) on triggers.
- **Endless Marquee Loops**: Continuously cycling horizontal slider with modal viewer and scroll state pausing.
- **Lenis Smooth Scroll Integration**: Native scroll alignment for linear easing math.

## Technical Details

- **Animation Engine**: `gsap`, `@gsap/ScrollTrigger`, `framer-motion`
- **Scrolling**: `lenis`
- **Icons**: `lucide-react`
- **Styling**: Tailwind CSS
