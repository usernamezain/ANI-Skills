# Kinetic Void Complete Landing Page

An outstanding digital layout built on deep WebGL canvas models, interactive spring physics, linear smooth scrolls, and modern glassmorphism.

## Features

- **The Interactive Distort Sphere (R3F)**: Renders a high-fidelity WebGL mesh sphere that deforms dynamically on mouse coordinates and animation states via `@react-three/fiber` and `MeshDistortMaterial`.
- **GSAP Timed Introductions**: Sequential timeline entry animations introducing elements smoothly.
- **Glass Navbar Structure**: Floating navigation bars using high-blur backdrops (`backdrop-blur-xl bg-white/5`).
- **Asymmetric Feature Bentos**: Staggered cards featuring subtle gradient reveals and micro-hover states.
- **Parallax Numeric Metrics**: Floating statistical layouts translating dynamically in reaction to viewport scroll parameters.

## Technical Details

- **3D Render Engine**: `three`, `@react-three/fiber`, `@react-three/drei`
- **Animation Frameworks**: `gsap`, `framer-motion`
- **Smooth Scroll**: `lenis`
- **Icons**: `lucide-react`
- **Styling**: Tailwind CSS
